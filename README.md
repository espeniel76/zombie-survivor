# 좀비 생존자

위에서 내려다보는 디펜스 게임. 가운데 **3×3 기지 9칸**에 아군을 세우고, 사방에서 몰려오는 좀비를 막는다.
아군은 상점에서 산다. **6등급 30명**(일반·고급·희귀·영웅·전설·신화)이 있다.

## 플레이

**https://espeniel76.github.io/zombie-survivor/** (로그인 없이 누구나, `main`에 올리면 자동으로 다시 배포)

## 실행

```bash
npm install
npm run dev        # http://localhost:5181
```

| 명령 | 하는 일 |
|---|---|
| `npm test` | 규칙(칸 이웃, 강화/판매 값, 웨이브 구성) 단위 테스트 |
| `npm run build` | `dist/`로 배포용 빌드 |
| `npm run smoke` | (dev 서버를 켠 뒤) Edge를 화면 없이 띄워 한 판 굴리고 `shots/`에 화면 저장 |
| `node scripts/autoplay.mjs 300` | 단순한 자동 플레이로 몇 웨이브까지 가는지 확인(균형 점검용) |
| `node scripts/sound-check.mjs` | (dev 서버를 켠 뒤) 모든 효과음을 구워 보고 길이·크기를 표로 확인 |

효과음은 dev 서버를 켠 뒤 http://localhost:5181/sounds.html 에서 하나씩 들어 볼 수 있다.

## 규칙 요약

- 웨이브 사이 쉬는 시간 20초(바로 시작 가능). 5웨이브마다 거대 좀비.
- 빈 칸을 누르면 상점, 아군을 누르면 강화(최대 Lv5)/옮기기/판매(쓴 돈의 절반).
- 좀비가 기지에 붙으면 기지 체력이 깎인다. 0이 되면 끝. 웨이브를 막을 때마다 기지 15% 수리.
- 기지를 공격 중인 좀비는 사거리와 상관없이 모든 아군이 노릴 수 있다(화염 계열만 예외).
- 지휘관은 상하좌우로 붙은 칸만 강화하므로 배치가 중요하다.
- 번쩍임 효과는 기본으로 꺼져 있다(설정에서 켜야 화면 흔들림·흰색 피격 번쩍임이 생김).

## 구조

```
src/data/allies.js    아군 등급과 30명 목록(수치·생김새·설명)
src/data/zombies.js   좀비 5종
src/core/rules.js     순수 규칙(테스트 대상)
src/core/sfx.js       효과음(파일 없이 합성 → 미리 구워 두고 재생, 압축기·공간 울림)
src/render/blob.js    동그라미 캐릭터(몸·하얀 눈·모자·무기) 그리기 — 게임과 mockup.html이 같이 씀
src/render/sprites.js 캐릭터 텍스처 생성, 아군 묶음(몸 + 좀비 쪽으로 기우는 무기)
src/scenes/Boot       그 밖의 그림(총알, 효과, 바닥, 소품)을 코드로 그려 텍스처 생성
src/scenes/Title      첫 화면, 아군 도감, 설정
src/scenes/Game       전장(좀비 이동, 아군 공격, 웨이브)
src/scenes/UI         위 정보, 아래 버튼, 상점, 아군 정보, 일시정지, 결과
```
